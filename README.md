# 👟 ShoeStore — Modern Footwear Shopping Website

A stylish, fast and fully responsive Shoe E-Commerce Website built with a modern UI design approach.  
This project focuses on clean product presentation, smooth user experience and a premium brand-like layout — similar to Nike, Adidas & Puma store designs.

> 🚀 **Designed & Developed by: Ankit Sharma**

---

## ✨ Features

- 🛍 Beautiful Shoe Product UI
- 🌗 Modern Minimalist Layout
- 📱 Fully Responsive for Mobile & Desktop
- 🧩 Product Cards with Price, Ratings & CTA Buttons
- 🎨 Smooth Color Palette + Typography
- ⚡ Fast Loading & Lightweight Frontend

---

## 🛠 Tech Stack

| Technology | Purpose |
|----------|-----------|
| HTML / JSX | Structure of UI |
| CSS / Tailwind / SCSS | Styling + Responsive Design |
| React / JavaScript | Components & UI Interaction |
| Swiper.js / Framer Motion *(optional)* | Slider + Animations |

> *Stack names are editable based on what you used.*
